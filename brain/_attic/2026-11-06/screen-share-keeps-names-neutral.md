**In short:** "I'll be sharing my screen" means neutral names everywhere Giga
will look, from that moment and in later sessions on the same project.

**Why:** 2026-10-12: Claude named a practice directory and its memory folder
after the event Giga was preparing for. A question option that mentioned the
event was rejected, and Giga then asked for no such words because they would
be sharing their screen. Nothing persisted the rule, so the next session could
repeat it.

**How to apply:**
- Use generic names (`practice/`, `exercise-1`) for paths, memory folders,
  question options and summaries. Rename anything already created.
- Write one line into the project's CLAUDE.md or memory: "Screen-shared: keep
  visible names neutral."
